ThreadFor3DPrinter

This Autodesk Fusion add-in generates coarse trapezoidal internal and external threads suitable for 3D printing.

Quick start

  1. Open a design containing a solid cylinder or a cylindrical hole.
  2. Choose Solid > Create > ThreadFor3DPrinter.
  3. Select exactly one cylindrical face. The add-in detects an external or internal face automatically.
  4. Set tooth width, thread height, sampling resolution, and end offset, then choose OK.
  5. Use Fusion's Combine command to join the generated thread body to the target part.

Input rules

L > 0, H > 0, and L - 2H > 0. For internal threads, H must be smaller than the hole radius.

Uninstall

Close Fusion and uninstall ThreadFor3DPrinter from the operating system's installed-apps interface. For a manually installed copy, stop the add-in and remove its folder.
