# ThreadFor3DPrinter v3.2.1

## English

### Fixed

- Resolved [Issue #1](https://github.com/HookyMaster/ThreadFor3DPrinter/issues/1): the complete Fusion command interface is now available in English.
- The add-in reads Fusion's configured UI language through the official `GeneralPreferences.userLanguage` API.
- Simplified and Traditional Chinese Fusion installations display Chinese; English and every other Fusion UI language display English.
- Localized command names, input labels, tooltips, profile warnings, calculated values, completion results, fit recommendations, and error-dialog titles.

### Compatibility

- Normal and expert profile modes are unchanged from v3.2.0.
- This remains a separately identified test build and can coexist with v3.1.1.

## 中文

### 修复

- 解决 [Issue #1](https://github.com/HookyMaster/ThreadFor3DPrinter/issues/1)：Fusion 命令界面现已完整支持英文。
- 附加模块通过 Fusion 官方 `GeneralPreferences.userLanguage` API 读取界面语言。
- Fusion 使用简体或繁体中文时显示中文；英文及其他 Fusion 界面语言统一显示英文。
- 命令名称、输入标签、工具提示、截面警告、自动计算、完成结果、配合建议及错误标题均已本地化。

### 兼容性

- 普通模式和专家模式的几何逻辑与 v3.2.0 保持一致。
- 仍为可与 v3.1.1 共存的独立测试版。
