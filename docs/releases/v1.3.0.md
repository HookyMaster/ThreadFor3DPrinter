# ThreadFor3DPrinter v1.3.0

## English

- Added an adjustable flank angle from 5° to 45°.
- Tooth height H and flank angle can be edited independently; tooth crest width and pitch are recalculated automatically.
- Added a minimum tooth crest width (crest flat) of 0.2 mm to prevent a degenerate or self-intersecting profile.
- When the requested H exceeds the valid value for the selected root width and flank angle, H is reduced automatically and the profile-status area explains the correction.
- Updated profile geometry, pitch calculation, completion results, and the headless Python/JSON API to use the selected flank angle.

## 中文

- 新增 5°–45° 可调牙侧角。
- 牙高 H 与牙侧角可独立修改，工具会自动重新计算牙顶宽度和螺距。
- 牙顶宽度（牙顶平宽）最小限制为 0.2 mm，避免牙型退化或截面自相交。
- 当输入的 H 超过当前牙底宽度和牙侧角允许的范围时，工具会自动降低 H，并在“截面状态”中说明修正原因。
- 截面几何、螺距计算、生成结果以及无界面 Python/JSON API 均已同步支持所选牙侧角。
