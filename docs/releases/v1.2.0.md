# ThreadFor3DPrinter v1.2.0

## Highlights

- Added headless Python automation through `generate_thread(...)` and
  `generate_thread_from_json(...)`.
- Unified GUI, direct Python, and JSON generation through the same modelling
  core.
- Added segmented sweep generation for long threads while preserving the
  linked pitch formula and cylindrical guide surface.
- Each successful generation is collected into one Fusion timeline group.
- Added English feature names and restored Chinese completion messages.
- Expanded the English and Chinese API documentation.

## Download

Download `ThreadFor3DPrinter-v1.2.0.zip` from this GitHub Release, extract the
`ThreadFor3DPrinter` folder, and place it in the Fusion 360 API add-ins
directory.

## 主要更新

- 新增 `generate_thread(...)` 和 `generate_thread_from_json(...)` 无界面
  Python 自动化接口。
- GUI、Python 直接调用和 JSON 调用统一使用同一个建模核心。
- 长螺纹改用分段扫掠，同时保留联动螺距公式和圆柱导向面。
- 每次成功生成的全部特征会放入一个 Fusion 时间线组。
- 使用英文特征名称，并恢复中文完成提示。
- 补充英文和中文 API 文档。

## 安装

从本次 GitHub Release 下载 `ThreadFor3DPrinter-v1.2.0.zip`，解压其中的
`ThreadFor3DPrinter` 文件夹，并将其放入 Fusion 360 API 附加模块目录。
