# ThreadFor3DPrinter v3.1.1

> Stable release. Graduates the turn-count and boolean-join rework from `v3.1.0-preview`, and adds sketch cleanup plus a tighter default clearance.

## English

### Improvements
- **Full-fill turn count, no wasted margin:** with lead-in/lead-out enabled or disabled, the thread now runs all the way to the cylinder end — `N = (height − offset − L) / pitch`. The lead ramp's natural taper acts as the end clearance, so no extra turns are spent on safety margin.
- **Cleaner timeline:** every sketch created during generation (helix paths, ramp sections, sweep profiles) is hidden automatically once the thread is finished. The sketches remain in the browser tree and can be shown again at any time.
- **Tighter default clearance:** the recommended per-side clearance for mating parts is now `0.2 mm` (was `0.3 mm`), i.e. `0.4 mm` on diameter. Every figure in the result dialog is derived from this single constant.

### Fixes
- **4-decimal turn count truncation:** the fractional turn count is floored to 4 decimals, guaranteeing the material end never crosses the end face.
- **Short-segment merge guard (`MIN_SEGMENT_TURNS = 1.0`):** a residual segment shorter than 1 turn is merged into the neighbouring segment, preventing spline degeneration at the thread end.
- **Per-thread-type lead overlap:** external threads use a `0.10`-turn overlap between the ramp loft and the main sweep, internal threads `0.05`. Fixes silent join failures on external threads (`D34.6/H10, L3/H1`) and `ASM_NULL_PARTNER_LOOP` on internal threads (`D110/H33, L1.6/H0.6`).
- **Join target = main sweep body:** the boolean target is now the main sweep segment instead of the smaller entrance loft, so the join no longer fails silently with disjoint bodies on some geometries.
- **Consistent clearance wording:** the legacy dialog path and both READMEs now derive the recommended clearance from the same constant instead of hard-coded numbers.

## 中文

> 正式版。将 `v3.1.0-preview` 的圈数计算与布尔合并重构转为稳定版本，并新增草图清理与更紧的默认间隙。

### 改进
- **满算圈数，不浪费余量：** 无论是否启用收口，螺纹都一直生成到圆柱端面——`N = (高度 − 偏移 − L) / 螺距`。收口渐变本身充当末端安全余量，不再为安全距离浪费圈数。
- **时间线更干净：** 生成过程中创建的草图（螺旋路径、收口截面、扫掠轮廓）在螺纹完成后自动隐藏。草图仍保留在浏览器树中，随时可手动重新显示。
- **默认配合间隙收紧：** 配合件建议单侧间隙由 `0.3 mm` 改为 `0.2 mm`（直径上 `0.4 mm`）。结果对话框中的所有数值均由这一个常量推导。

### 修复
- **圈数 4 位小数截断：** 小数圈数按 `floor` 截断到 4 位，保证材料末端永不越过端面。
- **短段合并保护（`MIN_SEGMENT_TURNS = 1.0`）：** 不足 1 圈的残余段并入相邻段，防止螺纹末端样条退化。
- **收口重叠量按螺纹类型分离：** 外螺纹收口放样与主扫掠之间重叠 `0.10` 圈，内螺纹 `0.05` 圈。修复外螺纹静默断开（`D34.6/H10, L3/H1`）与内螺纹 `ASM_NULL_PARTNER_LOOP`（`D110/H33, L1.6/H0.6`）。
- **合并目标改为主扫掠体：** 布尔目标从较小的入口放样体改为主扫掠段体，避免部分几何下合并静默失败、螺纹呈现断开。
- **间隙文案统一：** 旧版生成路径与两份 README 不再硬编码间隙数值，统一由同一常量推导。

## Compatibility

- Fusion 360 add-in, Windows and macOS.
- Public API unchanged (`generate_thread` / `generate_thread_from_json` keep their signatures).
