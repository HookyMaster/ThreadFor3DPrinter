# ThreadFor3DPrinter v3.0.0

## English

### New features
- Added **thread lead-in/lead-out ramps**: the first and last 1/8 turn of the thread now ramp the trapezoid section (tooth height + width) from 10% up to full size, so a mating part slides in easily and both thread ends stay print-friendly.
- Added a **Thread lead-in/lead-out** checkbox (default on) in the dialog so the ramps can be disabled to produce a full-height legacy thread.
- The ramp tip scale is automatically raised when the tooth height or crest width would drop below the ~0.2 mm print limit, so tiny teeth remain printable.
- The public API (`generate_thread` / `generate_thread_from_json`) accepts a new `enable_lead` parameter.

### Fixes
- **Robust thread-cylinder joining:** every trapezoid (sweep profile, per-segment profiles, ramp loft sections) now sinks its tooth root 0.02 mm radially below the cylinder surface, giving the boolean join real volume overlap. This fixes `ASM_INCONS_REL` / `ASM_EDGECOIN_PROBLEM` failures when joining a lead-in/lead-out thread to a clean full cylinder (previously diameter- and position-sensitive).
- **Generic sweep stability:** the main sweep path now uses pure native helix samples only — the ramp junction points are no longer inserted into the spline, so spline quality matches the no-ramp case and the guided sweep no longer fails with `ASM_SWEEP_ILLEGAL_SURFACE` at larger lead-out lengths.
- Tightened the default helix deviation tolerance from `0.5 × H` to `0.25 × H`, keeping fitted splines hugging the guide surface on clean offset cylinders.
- Adjacent sweep segments overlap slightly at their seams so multi-segment threads join reliably.

## 中文

### 新功能
- 新增**螺纹收口**：螺纹入口/出口各 1/8 圈将梯形截面（牙高+牙宽）从 10% 渐变到全尺寸，便于螺母/螺杆对位旋入，且两端更易打印。
- 对话框新增**螺纹收口**复选框（默认勾选），可取消以生成完整牙高的普通螺纹（旧版行为）。
- 当收口起始截面的牙高或牙顶宽度会低于约 `0.2 mm` 打印极限时，起始比例自动抬升，保证细小牙型仍可打印。
- 公共 API（`generate_thread` / `generate_thread_from_json`）新增 `enable_lead` 参数。

### 修复
- **螺纹与圆柱合并更稳健**：所有梯形截面（主扫掠轮廓、分段轮廓、收口放样截面）的牙根统一径向沉入圆柱面下 `0.02 mm`，使布尔合并具有真实体积重叠。修复了带收口螺纹在"干净完整圆柱面 + 位置偏移"下合并失败的 `ASM_INCONS_REL` / `ASM_EDGECOIN_PROBLEM`（此前对直径和位置敏感）。
- **扫掠稳定性通用修复**：主扫掠路径回归纯自然螺旋采样点，不再把收口衔接点插入样条——样条质量与无收口完全一致，不再因出口收口长度较大而触发 `ASM_SWEEP_ILLEGAL_SURFACE`。
- 默认螺旋偏差容差从 `0.5 × H` 收紧到 `0.25 × H`，保证拟合样条在偏移的干净圆柱面上始终贴合引导面。
- 相邻扫掠段在接缝处有少量体积重叠，多段长螺纹合并更可靠。
