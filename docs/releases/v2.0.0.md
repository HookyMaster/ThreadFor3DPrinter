# ThreadFor3DPrinter v2.0.0

## English

### New features
- Added a collapsible **advanced option** exposing the helix deviation ratio (path deviation as a fraction of the tooth height, default `0.5`) with a hover tooltip explaining its meaning.
- Added a **Join to cylinder** checkbox (default on) so the GUI can boolean-join the generated thread into the selected body, removing the seam between two separate bodies.
- The success dialog now shows a concrete recommended mating diameter using a suggested clearance (`0.3 mm` per side, a common FDM middle ground), instead of a "+ clearance" placeholder.
- The public API (`generate_thread` / `generate_thread_from_json`) accepts a new `deviation_ratio` parameter and reports the effective value in the result dict.

### Fixes
- Fixed `ASM_SWEEP_ILLEGAL_SURFACE` sweep failures on large diameters: the helix sampling now adapts to the cylinder radius so the path stays close to the guide face.
- Fixed a turn-count regression on long, large-diameter threads (segment indexing now maps turn boundaries to point indices proportionally; the point budget was raised to 20000 and turns are reduced rather than sampling density when exceeded).
- The helix deviation tolerance is now expressed as a fraction of the tooth height (`0.5 × H`) instead of a fixed value, matching the real kernel constraint.
- Timeline grouping is now best-effort; a grouping failure no longer aborts a successful generation.

## 中文

### 新功能
- 新增可折叠的**高级选项**，暴露“路径偏差系数”（螺旋路径偏差占牙高的比例，默认 `0.5`），鼠标悬浮可查看含义。
- 新增**合并到圆柱体**复选框（默认勾选），GUI 可将生成的螺纹布尔合并进所选圆柱体，消除两个独立实体之间的接缝。
- 生成成功提示现在给出基于建议间隙（单侧 `0.3 mm`，FDM 常用中间值）的具体建议配合直径，不再只是“+ 间隙”占位文字。
- 公共 API（`generate_thread` / `generate_thread_from_json`）新增 `deviation_ratio` 参数，并在返回结果中报告实际生效值。

### 修复
- 修复大直径下的 `ASM_SWEEP_ILLEGAL_SURFACE` 扫掠失败：螺旋采样现在随圆柱半径自适应，使路径始终贴合引导面。
- 修复长螺纹、大直径时的圈数回归（分段索引改为按圈数比例映射到点索引；总点数预算提到 20000，超出时减少圈数而非降低采样密度）。
- 螺旋路径偏差容差改为按牙高的比例表示（`0.5 × H`），取代固定值，与真实的内核约束一致。
- 时间线分组改为尽力而为；分组失败不再中断成功的生成。
