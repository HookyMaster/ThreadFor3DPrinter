# ThreadFor3DPrinter v3.2.0

## English

### Added

- Added a normal/expert mode switch. Normal mode remains the default and keeps the original linked L/H/α workflow.
- Expert mode independently exposes pitch P, crest width S, root width L, and tooth height H.
- Added live expert-mode warnings for base angles above 45°, overlapping teeth, and narrow crests.
- Crest widths from 0.08 mm to below 0.20 mm now recommend lowering layer height and adjusting line width without blocking generation.
- Added a documented M67 × 0.75 camera-filter thread case and printable test parameters.
- Added optional `pitch_mm` and `crest_width_mm` automation parameters while preserving legacy API calls.

### Test-build identity

- Uses a separate add-in and command ID so it can coexist with v3.1.1 during testing.
- The toolbar command is labelled `ThreadFor3DPrinter [TEST P/S]`.
- Startup is disabled by default for the test build.

## 中文

### 新增

- 新增普通/专家模式切换。普通模式默认启用，保留原来的 L/H/α 联动工作流。
- 专家模式可独立设置螺距 P、牙顶宽 S、牙底宽 L 和牙高 H。
- 新增底角大于 45°、相邻牙重叠和窄牙顶等实时风险警告。
- 牙顶宽度处于 0.08 mm 至 0.20 mm 以下时，提示降低层高并调整线宽，但不阻止生成。
- 新增 M67 × 0.75 相机滤镜螺纹特殊案例和试打印参数。
- 自动化 API 新增可选 `pitch_mm` 和 `crest_width_mm`，同时兼容旧调用方式。

### 测试版标识

- 使用独立的附加模块 ID 和命令 ID，可在测试期间与 v3.1.1 共存。
- 工具栏命令显示为 `ThreadFor3DPrinter [TEST P/S]`。
- 测试版默认不随 Fusion 自动启动。
