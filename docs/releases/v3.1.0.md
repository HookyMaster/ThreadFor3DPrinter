# ThreadFor3DPrinter v3.1.0-preview

> Preview release on the `dev` branch. The turn-count logic and boolean-join robustness have been reworked; please test and report issues before it graduates to a stable release.

## English

### Changes
- **Full-fill turn count without extra safety margin:** with lead-in/lead-out enabled or disabled, the thread now runs all the way to the cylinder end — `N = (height − offset − L) / pitch`. The lead ramp's natural taper provides the end clearance, so no extra turns are wasted.
- **4-decimal turn count truncation:** the fractional turn count is floored to 4 decimals, guaranteeing the material end never crosses the end face.
- **Short-segment merge guard (`MIN_SEGMENT_TURNS = 1.0`):** a residual segment shorter than 1 turn is merged into the neighbouring segment, preventing spline degeneration at the thread end.
- **Per-thread-type lead overlap:** external threads use a `0.10`-turn overlap between the ramp loft and the main sweep, internal threads `0.05`. Fixes silent join failures on external threads (`D34.6/H10, L3/H1`) and `ASM_NULL_PARTNER_LOOP` on internal threads (`D110/H33, L1.6/H0.6`).
- **Join target = main sweep body:** the boolean target is now the first (main) sweep segment instead of the smaller entrance loft, so the join no longer fails silently with disjoint bodies on some geometries.

### Fixes
- Combined internal/external thread merge failures reported after v3.0.0 (`ASM_INCONS_REL`, silent disconnection, `ASM_NULL_PARTNER_LOOP`) are addressed by the overlap and join-target changes above.

## 中文

> `dev` 分支的预览版。圈数计算与布尔合并稳健性已重构，请测试反馈后再升级为正式版。

### 变更
- **满算圈数，不留额外安全余量：** 无论是否启用收口，螺纹都一直生成到圆柱端面——`N = (高度 − 偏移 − L) / 螺距`。收口渐变本身充当末端安全余量，不再浪费圈数。
- **圈数 4 位小数截断：** 小数圈数按 `floor` 截断到 4 位，保证材料末端永不越过端面。
- **短段合并保护（`MIN_SEGMENT_TURNS = 1.0`）：** 不足 1 圈的残余段并入相邻段，防止螺纹末端样条退化。
- **收口重叠量按螺纹类型分离：** 外螺纹收口放样与主扫掠之间重叠 `0.10` 圈，内螺纹 `0.05` 圈。修复外螺纹静默断开（`D34.6/H10, L3/H1`）与内螺纹 `ASM_NULL_PARTNER_LOOP`（`D110/H33, L1.6/H0.6`）。
- **合并目标改为主扫掠体：** 布尔目标从较小的入口放样体改为主扫掠段体，避免部分几何下合并静默失败、螺纹呈现断开。
