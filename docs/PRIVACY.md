# Privacy Policy for ThreadFor3DPrinter

Effective date: July 22, 2026

ThreadFor3DPrinter is an Autodesk Fusion add-in published by HookyMaster.

## Data collection and use

ThreadFor3DPrinter does not collect, transmit, sell, share, or retain personal information, Autodesk account information, model data, usage analytics, or device information. All geometry processing is performed locally inside Autodesk Fusion.

## Third parties

The add-in does not send data to third-party services and does not include advertising, analytics, telemetry, or external tracking libraries. Autodesk Fusion itself is governed by Autodesk's own terms and privacy policy.

## Data retention and deletion

Because the add-in does not collect or retain user data, there is no user data held by the publisher to delete. Users may remove locally generated geometry using Autodesk Fusion's normal editing tools and may uninstall the add-in at any time.

## Consent and revocation

The add-in does not request consent for data processing because it performs no publisher-controlled collection or processing of personal data. Uninstalling the add-in stops all use of the add-in.

## Changes

Material changes to this policy will be published in this repository with a new effective date.

## Contact

For privacy or support questions, open an issue at:

https://github.com/HookyMaster/ThreadFor3DPrinter/issues

# ThreadFor3DPrinter 隐私政策

生效日期：2026 年 7 月 22 日

ThreadFor3DPrinter 是由 HookyMaster 发布的 Autodesk Fusion 附加模块。

本附加模块不会收集、传输、出售、共享或保留个人信息、Autodesk 账户信息、模型数据、使用分析或设备信息。所有几何计算都在 Autodesk Fusion 内本地完成。本附加模块不包含广告、分析、遥测或外部跟踪组件，也不会把数据发送给第三方服务。

由于本附加模块不收集或保存用户数据，发布者没有需要保留或删除的用户数据。用户可以随时使用 Autodesk Fusion 的正常编辑功能删除生成的几何体，并可随时卸载本附加模块。

如有隐私或支持问题，请在以下页面提交 issue：

https://github.com/HookyMaster/ThreadFor3DPrinter/issues
